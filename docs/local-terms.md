# フィルタ辞書(config/local-terms.json)

一次フィルタ(仕様書 §7)が照合する地元関連語彙の辞書。起動時に 1 回だけ読み込むため、変更後はサーバの再起動が必要。

## 形式

```json
{
  "terms": [
    { "term": "見出し語" },
    { "term": "見出し語", "patterns": ["正規表現", "正規表現"] }
  ]
}
```

| キー | 必須 | 内容 |
|---|---|---|
| `term` | ○ | 見出し語。発言に部分一致すれば該当とする。トリガ時のログにもこの語が出る |
| `patterns` | | 表記揺れを拾う正規表現(JavaScript の `RegExp`、`u` フラグ付き)の配列。いずれかに一致すれば該当とする |

## 正規化

照合の前に、発言と見出し語の両方に次の正規化をかける(`src/local-filter.js` の `normalize`)。

- 全角半角の統一(NFKC)
- カタカナ → ひらがな
- 英字の小文字化

`patterns` の正規表現は**正規化後の文字列**に対して照合するため、カタカナではなくひらがな、英大文字ではなく小文字で書くこと。

## 運用方針

取りこぼし最小の緩い運用とし、絞り込みは LLM に委ねる(仕様書 §7)。迷った語は登録してよい。
